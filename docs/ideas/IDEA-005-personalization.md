# IDEA-005: Bookmarks and private notes

Status: inbox
Stage: Later

## Problem and audience
Returning users want to save items and their own context.

## Smallest useful version
Bookmarks first; private notes only if validated.

## Evidence and dependencies
Origin: initial design; demand has not yet been validated. Evidence of return usage and a decision about accounts versus device-local storage.

## Acceptance criteria
Users can save and retrieve an item; private notes are not publicly exposed.

## Open questions
Is cross-device sync worth introducing accounts?
