# IDEA-006: Public comment assistance

Status: inbox
Stage: Participation experiments

## Problem and audience
Residents may struggle to prepare and deliver comments.

## Smallest useful version
Drafting and copy/export before delegated submission. A submission feature requires explicit per-comment approval, destination verification, receipt/failure feedback, and duplicate prevention.

## Evidence and dependencies
Origin: initial design; demand has not yet been validated. Verified agency rules and deadlines, clear handling of personal information, and an operating owner.

## Acceptance criteria
A user can review the exact text and intended recipient before any submission; failed delivery is never reported as success.

## Open questions
Does assistance solve the problem without operating a submission service?
