# IDEA-008: Multilingual access

Status: inbox
Stage: Broader access

## Problem and audience
English-only summaries and participation tools may exclude residents.

## Smallest useful version
One prioritized language; cache translations by source version and language, show the original, and flag stale translations.

## Evidence and dependencies
Origin: initial design; demand has not yet been validated. Language demand, translation quality review, and source version tracking.

## Acceptance criteria
A changed original invalidates its translation; users can access the original and report errors.

## Open questions
Which languages and how to review translated participation instructions? Bilingual comment submission depends on IDEA-006.
