# IDEA-011: Archive, search, and agent access

Status: inbox
Stage: Broader access

## Problem and audience
Residents and researchers need to trace an issue across documents and meetings.

## Smallest useful version
Page-separated text exports in the ingestion foundation; add keyword search and incremental historical backfill later.

## Evidence and dependencies
Origin: initial design; demand has not yet been validated. Reliable source identity, document versioning, and measured storage/processing cost.

## Acceptance criteria
Search results resolve to the correct source version and page; extraction gaps are visible.

## Open questions
How much history is valuable? Does agent access need an API beyond text exports?
